# Локальное демо интерфейса Guard

Отдельный инструмент разработки, не защита компьютера и не установщик. Работает от обычного пользователя; запуск с правами администратора отклоняется. Окно постоянно помечено «ДЕМО». Тот же XAML, рендерер QR и обработчики включены из `src/Guard.Setup`, не скопированы.

Ответы службы/сервера вымышлены и существуют только в памяти. Нет подключения к SCM/IPC/HTTP, изменения аккаунтов/политик, чтения GuardOperator, настоящих ключей и записи профиля. Экспорт намеренно недоступен. QR использует `https://preview.invalid` и случайные тестовые данные; **не сканировать настоящим телефоном**. Сбрасывать тестовое окно можно; реальные VM/телефонные привязки это не затрагивает.

## Открыть демо

Из корня `C:\Projects\guard-windows-client`:

```powershell
dotnet run --project tools/Guard.Setup.Preview/Guard.Setup.Preview.csproj -c Release
```

После сборки можно открыть `tools\Guard.Setup.Preview\bin\Release\net10.0-windows\Guard.Setup.Preview.exe` без UAC. Не путать с рабочим `src\Guard.Setup\...\Guard.Setup.exe`.

1. В большом окне нажать «Проверить установку». Результаты относятся только к вымышленному компьютеру.
2. Прокрутить вниз до «Привязать телефон» и нажать её. QR помещается в область окна; в фоне идут вымышленные запросы с задержкой.
3. В маленьком окне «Guard — управление ДЕМО» нажать «Телефон ответил: показать код сравнения». Вернуться в большое окно; восемь строк появятся после фонового запроса. Галочка и «Подтвердить привязку» меняют только демонстрационное состояние.
4. Для проверки ошибки использовать «Связь пропала»; затем «Связь восстановилась» и «Проверить привязку» в большом окне. При ошибке QR скрывается, автоматическая проверка останавливается.
5. «Новый тест с чистого экрана» открывает новое вымышленное состояние. Закрыть маленькое окно — закончить демо целиком. Срок одной попытки — пять минут.

Потеря фокуса скрывает QR/код сравнения, как в рабочем окне. После возвращения отметку сравнения нужно поставить заново.

## Воспроизводимая проверка

```powershell
dotnet run --project tools/Guard.Setup.Preview/Guard.Setup.Preview.csproj -c Release -- --check
```

Нужен разблокированный рабочий стол обычного пользователя. Проверка открывает и закрывает только свои демо-окна, переключая фокус между ними; не взаимодействовать с ними до окончания. Это отдельный интерактивный gate, а не часть headless safe suite.

Проверяет: ноль переключений доступности при двух неизменных фоновых ответах; QR без пересоздания/обрезки при ширине 760 и 420 DIP; полный восьмистрочный код и отдельное согласие; сброс сравнения при потере фокуса; потерянный ответ подтверждения без повторной команды; отказ сети/ручной повтор; два клика во время чтения без дублирования/перекрытия; отказ от устаревшего действия после смены версии; истечение срока; закрытие во время чтения без remote cancel.

07.10.2026 старая логика воспроизведённо дала `Background polling toggled buttons: 16`, исправленная прошла все проверки. Fresh Release/29 v2 harnesses/45 legacy checks PASS. Живой визуальный просмотр демо подтвердил целиком видимый QR и доступный нижний ряд кнопок. Камера, настоящий телефон, другой DPI/скринридер и системные VM-сценарии этим не проверены.
